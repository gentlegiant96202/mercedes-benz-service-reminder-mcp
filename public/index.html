Mercedes-Benz Service Reminder MCP

A free, stateless Model Context Protocol server by SilberArrows. It lets AI assistants estimate your next Mercedes-Benz Service A or Service B, explain what each service includes, give general guidance on common warning lights and share contact details for a Mercedes-Benz specialist in Dubai. It works offline and collects no personal data.

How to connect

Endpoint (Streamable HTTP): /mcp

Add it to any MCP client that supports remote servers, for example:



Or run it locally over stdio: npx mercedes-benz-service-reminder-mcp
